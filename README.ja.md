# CSW (Claude Subscription Worker)

**自分の Claude CLI(`claude -p`)をローカル REST API で包む、個人向け開発者ツール。**

> [**NSKit**](https://github.com/nskit-io/nskit-io) プロジェクトの開発者ツール — *型にはまっているから、無限に組み合わせられる*。CSW は個人・開発用のツールです。自分がサインインしている Claude CLI を、自分のスクリプトやローカルツールから、自分のマシン(またはプライベートネットワーク)上の REST API 経由で呼び出せるようにします。商用・プロダクションサービスのバックエンドではありません。

---

## 問題

Claude API は**トークン従量課金**です。リクエストごとに入力・出力トークンが計量されるため、処理量に比例して請求額も増えます。

一方、Claude サブスクリプションは**月額定額**で、プランの利用上限の範囲内で CLI(`claude -p`)から使えます。

**CSW はこの CLI を自分用に包みます**。Claude CLI を REST API サーバの背後に置き、個人のスクリプト・ローカルツール・開発中の実験から、セッション・プリセット・キャッシュ付きで呼び出せるようにします。

> **利用範囲。** Claude サブスクリプションは契約者本人の利用のためのもので、Anthropic の利用ポリシーとプラン上限に従います。CSW は本人の個人・開発作業にのみ使ってください。他のユーザーに提供する製品・サービス、商用・プロダクションのワークロードには [Claude API](https://www.anthropic.com/api) を使ってください。最新の API 価格とプラン情報: [anthropic.com/pricing](https://www.anthropic.com/pricing)。

---

## どちらを使うか

| | Claude API | CSW 経由の自分のサブスクリプション |
|---|---|---|
| 課金 | トークン単位 | 本人の月額定額プラン |
| スループット | 並列、API 料金ティアのレート制限 | プラン上限とワーカーセッション数で制限 |
| 用途 | 他のユーザー向けの製品・サービス、商用・プロダクションのワークロード | 本人の個人・開発作業: スクリプト、ローカルツール、実験 |

レスポンス・キャッシュを有効にすると、キャッシュヒット時は Claude を呼び出さないため、繰り返しのローカル呼び出しが速くなり、プラン上限内に収まります。

## アーキテクチャ

CSW は2つのモードで動作します:

### Standard モード

ステートレス処理。各リクエストは新しい `claude -p` プロセスを起動し、実行して返します。

- **利点**: シンプル、確実、状態管理不要
- **欠点**: コールドスタート(~14-40 秒/リクエスト)、会話文脈なし
- **向き**: ワンオフ処理、バッチジョブ

### Worker モード(v2)

永続 tmux ベース・セッション。Claude が tmux セッションで常駐し、ファイルベースの inbox/outbox 経由でコマンドを受け取ります。

- **利点**: リクエストごとに速い(リクエスト毎の ~14-40 秒のコールドスタートなし)、会話文脈維持、`alwaysOn` 対応
- **欠点**: より複雑なライフサイクル管理、初期セッション作成 ~16 秒
- **向き**: 対話型ローカルツール、会話型ワークフロー、頻繁なリクエスト

## 機能

- REST API(Express.js)
- MySQL によるセッション、メッセージ、メモリ、プリセット、キャッシュの永続化
- Worker Manager による並列 tmux セッション管理
- プロンプトプリセット(再利用可能なシステムプロンプト)
- レスポンス・キャッシング
- 会話メモリ(スレッド単位)

## セキュリティ

CSW はホスト上で CLI と tmux セッションを動かすため、API は管理用の面として扱います。

- **公開インターネットに露出しない。** 内部ネットワークで運用し、前段に認証プロキシか IP 許可リストを置きます。リファレンス・サーバには組み込みの認証がありません。
- **ホストに届く識別子はすべて検証する。** ワーカー名は許可文字パターン(`^[a-z0-9][a-z0-9-]{0,31}$`)に一致する必要があり、それ以外は `400` で拒否します。
- **シェル文字列ではなく argv で実行する。** `tmux` などの外部コマンドには値を個別の引数(`execFile` 方式)として渡し、コマンド文字列に埋め込みません。
- **ワーカーは非特権アカウントで実行する。** sudo 権限がなく、ワーカー用ディレクトリにのみアクセスできる専用 OS ユーザーを使います。
