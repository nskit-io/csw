# CSW (Claude Subscription Worker)

**定額の Claude サブスクリプションを、スケール可能な AI 処理 API に。**

> [**NSKit**](https://github.com/nskit-io/nskit-io) のインフラ構成要素 — *型にはまっているから、無限に組み合わせられる*。CSW は NSKit プロダクション・サービスの AI 処理層を担い、サブスクリプション層の Claude をコスト効率の良いバックエンド機能に転換します。

---

## 問題

Claude API は**トークン従量課金**です。リクエストごとに入力・出力トークンが計量されるため、処理量に比例して請求額も増えます。

一方、Claude サブスクリプションは**月額定額**で、プランの利用上限の範囲内で CLI(`claude -p`)から使えます。

**CSW はこのギャップを橋渡しします**。Claude CLI を REST API サーバでラップし、安定してキャッシュ可能なバックエンド処理を、従量課金ではなく定額サブスクリプション上で動かせるようにします。

> 最新の API 価格とプラン情報: [anthropic.com/pricing](https://www.anthropic.com/pricing)。サブスクリプションの利用は Anthropic の利用ポリシーとプラン上限に従います。CSW は正当な処理ワークロード向けであり、乱用を目的としません。

---

## コスト構造

価格は変わるため、この文書では数値を固定しません。違いは構造にあります。

| | トークン従量 API | CSW 経由の定額サブスクリプション |
|---|---|---|
| コストの形 | 処理トークンに比例して増加 | 月額固定 |
| スループット | 並列、API 料金ティアのレート制限 | プラン上限とワーカーセッション数で制限 |
| 向いている場面 | 変動が大きい・少量のトラフィック、厳しい SLA | 安定したトラフィック、反復プロンプト、キャッシュ可能な応答 |

レスポンス・キャッシュを有効にすると、キャッシュヒット時は Claude を呼び出さないため、安定したワークロードほどリクエスト単価は下がっていきます。

## アーキテクチャ

CSW は2つのモードで動作します:

### Standard モード

ステートレス処理。各リクエストは新しい `claude -p` プロセスを起動し、実行して返します。

- **利点**: シンプル、確実、状態管理不要
- **欠点**: コールドスタート(~14-40 秒/リクエスト)、会話文脈なし
- **向き**: ワンオフ処理、バッチジョブ

### Worker モード(v2)

永続 tmux ベース・セッション。Claude が tmux セッションで常駐し、ファイルベースの inbox/outbox 経由でコマンドを受け取ります。

- **利点**: 2.5 倍高速(コールドスタートなし)、会話文脈維持、`alwaysOn` 対応
- **欠点**: より複雑なライフサイクル管理、初期セッション作成 ~16 秒
- **向き**: ユーザー向け API、会話型ワークフロー、高頻度リクエスト

## 機能

- REST API(Express.js)
- MySQL によるセッション、メッセージ、メモリ、プリセット、キャッシュの永続化
- Worker Manager による並列 tmux セッション管理
- プロンプトプリセット(再利用可能なシステムプロンプト)
- レスポンス・キャッシング
- 会話メモリ(スレッド単位)

## セキュリティ

CSW はホスト上で CLI と tmux セッションを動かすため、API は管理用の面として扱います。

- **公開インターネットに露出しない。** 内部ネットワークで運用し、前段に認証プロキシか IP 許可リストを置きます。リファレンス・サーバには組み込みの認証がありません。
- **ホストに届く識別子はすべて検証する。** ワーカー名は許可文字パターン(`^[a-z0-9][a-z0-9-]{0,31}$`)に一致する必要があり、それ以外は `400` で拒否します。
- **シェル文字列ではなく argv で実行する。** `tmux` などの外部コマンドには値を個別の引数(`execFile` 方式)として渡し、コマンド文字列に埋め込みません。
- **ワーカーは非特権アカウントで実行する。** sudo 権限がなく、ワーカー用ディレクトリにのみアクセスできる専用 OS ユーザーを使います。

## NSKit での利用

NSKit プロダクション・サービスの AI 処理レイヤーとして稼働中。Gemini/GPT/Claude を混在させる代わりに、サブスクリプション・ティアで統一することでコストを予測可能にしています。
